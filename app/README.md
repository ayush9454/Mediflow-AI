# MediFlow Android app

See the [project README](../README.md) and [development setup](../docs/development.md) for the implementation status, commands, API configuration, and validation limits.

Debug builds offer explicitly labeled patient, doctor and administrator interface previews. These are not authenticated sessions and contain no patient records. Release builds cannot enable previews. Real Firebase sign-in is tracked in [ticket 04](../.scratch/mediflow-mvp/issues/04-authentication-authorization.md).
